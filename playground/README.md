# Playground Area

Este diretório destina-se a experimentações de código, rascunhos de layouts e novos componentes de interface.

---

## Regra do Projeto:
Nenhum arquivo colocado nesta pasta deve ser integrado ou importado pelo código oficial de produção localizado em `lib/`. Ela serve exclusivamente para testes isolados e prototipagem rápida de renderizadores.
