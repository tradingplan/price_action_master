# XP (Gamification) Schema Documentation

Este documento dita como a experiência (XP) e níveis de conquistas de trading são contabilizados e salvos no dispositivo.

---

## 1. Tabela de Distribuição de XP

| Evento | Pontuação de XP | Origem / Tipo |
| :--- | :---: | :--- |
| Conclusão de Lição | +10 XP | Leitura de Lesson |
| Conclusão de Exercício | +20 XP | Checklist validado |
| Acerto de Pergunta de Quiz | +15 XP | Por acerto de quiz |
| Conclusão de Desafio de Módulo | +50 XP | Salvo no encerramento |
| Conclusão Total de Curso | +200 XP | Liberação de Certificado |

---

## 2. Níveis de Conquista (Trader Levels)

A pontuação acumulada eleva o nível técnico demonstrado na interface da Home:
*   **0 a 500 XP:** Trader Aprendiz 🕯️
*   **501 a 1500 XP:** Grafista de Elite 📈
*   **1501 a 3500 XP:** Especulador Consistente 🛡️
*   **3501+ XP:** Mestre Price Action 👑
