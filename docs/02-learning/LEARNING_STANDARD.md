# Learning Standard: Conceptual Instruction Framework

Este documento estabelece as regras pedagógicas de estruturação conceitual para os cursos do ecossistema **Price Action Master**.

---

## 1. Estrutura Modular
Cada disciplina deve ser subdividida em módulos sequenciais autônomos. Um módulo não deve assumir conhecimentos complexos não explicados em etapas anteriores.

---

## 2. Padrão de Lição
As lições conceituais são as bases teóricas de cada módulo. Devem seguir a seguinte estrutura de apresentação de conteúdo:
1.  **Introdução ao Fenômeno:** Apresentar o conceito no mercado (ex: o que é a rejeição no suporte).
2.  **Psicologia de Bastidores:** Explicar *por que* o fenômeno acontece (ex: compradores institucionais montando posições).
3.  **Regra Operacional Clara:** Indicar o gatilho exato que valida o padrão.

---

## 3. Uso de Exemplos Visuais (Canvas)
Cada lição deve ser acompanhada de pelo menos um diagrama dinâmico vetorial ilustrando o conceito. O diagrama deve ser simples, limpo e focar estritamente no detalhe ensinado, evitando excesso de ruídos ou linhas secundárias.
