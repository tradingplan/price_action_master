# Pedagogy and Spaced Repetition (Leitner System)

Fundamentação pedagógica do ecossistema **Price Action Master**.

---

## 1. Princípios de Andragogia (Ensino de Adultos)
O ensino de finanças e trading para adultos exige:
*   **Orientação Prática:** O aluno deve ver aplicação imediata para o que aprendeu (uso imediato de exercícios).
*   **Auto-direcionamento:** O aluno controla seu ritmo navegando pelas abas do módulo.
*   **Conexão com Erros Anteriores:** Explicações profundas que mostram a contradição de análises simplistas de mercado.

---

## 2. Sistema Leitner de Repetição Espaçada
Para fixar a leitura estrutural (como identificar BOS/CHoCH corretos), a plataforma planeja aplicar o Sistema Leitner para gerenciamento local de flashcards de quiz:
*   **Caixa 1:** Quizzes novos ou respondidos incorretamente (revisão diária).
*   **Caixa 2:** Quizzes respondidos corretamente uma vez (revisão a cada 3 dias).
*   **Caixa 3:** Quizzes dominados (revisão semanal).
*   *Nota: O erro de um quiz na Caixa 2 ou 3 faz com que o card retorne imediatamente para a Caixa 1.*
*   Toda a lógica de progresso de caixas Leitner deve ser calculada e mantida localmente no `LocalDataManager`.
